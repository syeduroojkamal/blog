# How to trace normal raster images to SVG using Figma
- Select an image from the internet that you want to convert into a rough SVG
- Paste the image into Figma
- Use the Pen tool (in the bottom toolbar)
- Start tracing the image
- Once your vector diagram is complete
- Select your diagram
- Scroll down in the right-hand menu, and look for "Export"
- Select SVG from the dropdown menu
- Click "Export"
